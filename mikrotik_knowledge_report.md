# База знаний MikroTik (RouterOS v7)

Данный отчет содержит консолидированную информацию по ошибкам, архитектуре сети и лучшим практикам настройки устройств MikroTik.

---

## 1. База ошибок (Known Issues & Bugs)

### RouterOS v7.21 (Последняя стабильная)
*   **Улучшения BGP:** Исправлены ошибки декодирования l2vpn-cisco и коррупция меток MPLS.
*   **Bridge:** Исправлено создание динамических VLAN на switch-cpu (ошибка v7.20).
*   **Производительность:** Для arm64 добавлена поддержка Receive Packet Steering (RPS) в `/system/resource/irq/rps` для балансировки нагрузки на CPU.

### RouterOS v7.19 - v7.20
*   **WireGuard:** Исправлены проблемы стабильности FastPath.
*   **CAPsMAN:** Исправлены критические ошибки роуминга FT (Fast Transition).
*   **Bridge:** Исправлены возможные падения системы при удалении интерфейсов из моста с активным fast-path.

### RouterOS v7.18
*   **CAPsMAN:** Зафиксированы случаи разрыва соединений при переходе клиентов (FT transition).
*   **WireGuard:** Ошибка MTU при использовании FastPath (некорректный Path MTU Discovery).

### RouterOS v7.15
*   **WiFi:** Утечка памяти в пакете `wifi-qcom` при частой ротации DHCP-аренд.
*   **Драйверы ax:** Нестабильность роуминга на ранних версиях драйверов WiFi 6.

## 2. База строения сети (Модели и возможности)

### Высокопроизводительные (Core/Aggregation)
*   **RB5009UG+S+IN:** 4 ядра, 1.4 ГГц, 1 ГБ ОЗУ. SFP+ (10G), 2.5G Ethernet.
    *   *Назначение:* Средний офис, VPN-шлюз, Docker контейнеры.
    *   *Особенности:* Полный аппаратный оффлоад L3 (IPv4), отличная поддержка WireGuard (до 2.5 Гбит/с).
*   **CCR2116 / CCR2216:** Для высоконагруженных узлов и BGP Full Table.

### Домашние и малый офис (SOHO)
*   **hAP ax3:** Флагман SOHO. Wi-Fi 6, 2.5G порт, мощный CPU (1.8 ГГц).
    *   *Назначение:* Современный дом, малый офис с AX-клиентами.
*   **hAP ax2 / cAP ax:** Оптимальные точки доступа Wi-Fi 6.
*   **hAP ac2:** Устаревающая, но популярная модель. Ограничена по ОЗУ (128 МБ), не поддерживает контейнеры и ZeroTier.

## 3. База правильного написания конфигов (Best Practices)

### Безопасность (Hardening)
1.  **Management VLAN:** Администрирование только через выделенную VLAN (MGMT). Запрет доступа к Winbox/SSH из обычных пользовательских сетей.
2.  **WAN Protection:** Правило `action=drop chain=input in-interface-list=WAN connection-state=new` — база защиты роутера.
3.  **DNS Security:** Если `allow-remote-requests=yes`, обязательно блокировать входящие UDP/53 на WAN, чтобы не стать участником DNS Amplification атаки.
4.  **Сервисы:** Отключить неиспользуемые (`/ip service`): telnet, ftp, api, api-ssl (если не используются).

### Сетевая архитектура
*   **Bridge VLAN Filtering:** На новых устройствах (чипы Marvell, Realtek в ax-серии) использовать только ОДИН мост и `vlan-filtering=yes`. Это активирует L2 Hardware Offloading.
*   **FastTrack:** Ускоряет трафик, но несовместим с Queue Tree, IPsec и Traffic Flow. Если нужен QoS — FastTrack должен быть выключен.

### Беспроводные сети (WiFi/CAPsMAN)
*   **Новый CAPsMAN (wifi-qcom):** Начиная с v7.13, для ax-устройств используется новый контроллер.
*   **Роуминг:** Обязательно настраивать FT (802.11r) и использовать Access List для управления клиентами (минимальный сигнал -80 dBm).
*   **Частоты:** Использовать только непересекающиеся каналы в 2.4 ГГц (1, 6, 11).
